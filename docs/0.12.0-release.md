# Retto 0.12.0

Apple Silicon Mac · macOS 13 이상. AI 도구 연동에는 Node.js도 필요합니다.

## 다운로드와 설치

[Retto 0.12.0 DMG 다운로드](https://github.com/rehyundesign/retto/releases/download/v0.12.0/Retto-0.12.0.dmg)

```sh
brew tap rehyundesign/retto
brew upgrade --cask retto   # 처음이면 brew install --cask retto
```

1. DMG를 열고 Retto.app을 Applications로 옮깁니다.
2. 기존 레토를 종료하고 새 앱을 실행합니다. 실행 중인 앱은 하나만 유지합니다.
3. 첫 실행이 차단되면 macOS 시스템 설정 → 개인정보 보호 및 보안에서 ‘그래도 열기’를 선택합니다. 이 배포는 Apple Developer ID 서명·공증을 받지 않았습니다. brew 로 설치하면 이 단계가 없습니다.

## 이번 버전 — Orca 에서 띄운 세션

- Orca 의 Claude·Codex 채팅과 Orca 터미널 탭에서 띄운 세션을 알아보고, 누르면 Orca 의 그 탭으로 갑니다. 메뉴에 「· Orca」가 붙습니다.
- Orca 의 Codex 채팅이 레토에 보입니다. Codex 쪽에 제목이 없어 숨겨지던 것을 Orca 의 채팅 제목으로 표시합니다.
- Orca 의 Codex 채팅이 승인·질문을 기다리면 입력 대기(파랑)로, 턴이 실패하면 실패(빨강)로 표시합니다. Orca 가 Codex 훅을 끄기 때문에 Orca 가 채팅 탭에 붙여 두는 상태를 읽습니다.
- Orca 의 내부 기록은 읽기만 하고, 응답·승인을 보내지 않습니다. Orca 가 꺼져 있으면 아무것도 하지 않습니다.
- 자세한 동작과 「Orca 업데이트 때 확인할 것」은 [세션 열기](세션-열기.md#orca-에서-띄운-세션)에 있습니다.
- 리락쿠마 2종은 공개 배포에 포함하지 않습니다. 14종 전체는 [로컬 동일본](20261113-local-snapshot.md)에 있습니다.

## 소스에서 빌드

```sh
git clone https://github.com/rehyundesign/retto.git
cd retto
git checkout v0.12.0
macos/scripts/build.sh --install
```

Xcode 명령줄 도구가 필요합니다(`xcode-select --install`).
