# Retto 0.11.0

Apple Silicon Mac · macOS 13 이상. AI 도구 연동에는 Node.js도 필요합니다.

## 다운로드와 설치

[Retto 0.11.0 DMG 다운로드](https://github.com/rehyundesign/retto/releases/download/v0.11.0/Retto-0.11.0.dmg)

1. DMG를 열고 Retto.app을 Applications로 옮깁니다.
2. 기존 레토를 종료하고 새 앱을 실행합니다. 실행 중인 앱은 하나만 유지합니다.
3. 첫 실행이 차단되면 macOS 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 내용을 확인하고 ‘그래도 열기’를 선택합니다. 이 배포는 Apple Developer ID 서명·공증을 받지 않았습니다.
4. 레토의 ‘AI 연동 확인’에서 훅과 Node.js 상태를 확인합니다.
5. Slack은 ‘Slack 설정… → 처음 연결하시나요? 연결 안내 ↗’에서 연결합니다. 계정·토큰·기존 메시지는 배포 파일에 포함하지 않습니다.

## 이번 버전

- Slack DM을 직접 읽거나 레토에서 열었을 때 알림을 해제하는 경로를 수정했습니다. 열기 중 새로 도착한 메시지는 유지합니다.
- 실제로 진행 중인 Codex·VS Code 작업이 오래됐다는 이유로 대기 상태가 되지 않게 했습니다. 완료된 고정 세션은 진행 중 작업에 표시를 넘깁니다.
- Slack 연결을 네 단계로 설명하는 로컬 HTML 안내, 설정 JSON 복사, 토큰 발급 위치 툴팁과 오류별 도움말을 추가했습니다.
- 안내 페이지는 레토의 크림색 말풍선, 살구색 버튼, 둥근 카드 스타일로 구성했습니다.
- 검증한 최종 로컬 앱과 같은 상태 연동·동작 소스를 사용합니다. 공개 스킨 12종의 프레임과 효과 리소스를 포함합니다. 기존 비공개 리락쿠마 2종은 배포에 포함하지 않습니다.

## 소스에서 빌드

```sh
git clone https://github.com/rehyundesign/retto.git
cd retto
git checkout v0.11.0
python3 scripts/build-public.py
```

Xcode 명령줄 도구가 필요합니다. `macos/runtime-resources.json`에 모든 번들 리소스의 저장소 경로와 SHA-256을 기록했습니다. 빌드는 해당 파일의 해시를 확인하고 임시 폴더에 앱을 만듭니다. 로컬 설치 앱이나 개인 작업 폴더에서 파일을 가져오지 않습니다. 기존 앱과 사용자 설정은 `--install` 없이 변경하지 않습니다.

빌드 중 상태·Slack·스킨 검사 20종과 상태 연동 Python 검사 3종을 실행합니다. 통과한 앱만 DMG로 만듭니다. DMG에는 설치 안내와 진단 도구를 함께 넣습니다.
