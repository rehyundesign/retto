# Retto 0.12.1

[Retto 0.12.1 DMG 다운로드](https://github.com/rehyundesign/retto/releases/download/v0.12.1/Retto-0.12.1.dmg) · `brew upgrade --cask retto`

설치 방법은 [0.12.0 안내](0.12.0-release.md)와 같습니다.

## 이번 버전

- Orca 의 Codex 채팅이 일하는 중인데 회색(쉬는 중)으로 보이던 것을 고쳤습니다. 레토가 Codex 앱의 실시간 상태에 Orca 스레드를 물어보다 「확인 불가」로 떨어졌습니다.
- Orca 에서 멈춘 턴은 쉬는 중으로 표시합니다. 예전에는 롤아웃에 완료가 없어 작업 중으로 남았습니다.
- 실패한 턴이 롤아웃상 작업 중일 때 실패가 가려지던 것을 고쳤습니다.
- Windows 베타도 같은 번호(0.12.1-beta.1)로 맞췄습니다 — Codex 롤아웃으로 task 찾기와 Orca 세션 표시가 들어갔습니다. 아직 맥과 다른 것은 [Windows 판](windows.md)에 있습니다.
