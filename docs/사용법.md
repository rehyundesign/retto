# 메뉴에서 무엇을 고를 수 있나

설치한 뒤 실제로 누르게 되는 것들. 왜 이렇게 동작하는지는 [화면에 보이는 것](오버레이.md)과
[클릭하면 어디로 가는가](세션-열기.md) 에 있다.

레토를 우클릭하거나 메뉴 막대의 발바닥 아이콘을 누르면 메뉴가 열린다.

## 누르는 곳마다 하는 일이 다르다

| 누르는 곳 | 하는 일 |
| --- | --- |
| **몸통** | 한 번 뛰어오르며 그 세션이 사는 창을 앞으로 보내고 세션까지 되살린다. VS Code 면 새 창을 만들지 않고 그 탭을 되살린다 |
| **⌥ + 클릭** | 창만 앞으로 보내고 탭은 건드리지 않는다. 세션 목록에서 고를 때도 같다 |
| **말풍선** | 몸통과 같다. 마우스를 올리면 오른쪽에 ↗ 가 나타난다 |
| **빨간 배지** | 손이 필요한 세션이 하나면 바로 열고, 여럿이면 목록을 띄운다. 배지는 끌어서 레토의 네 모서리 어디로든 옮길 수 있고 그 자리를 기억한다 |
| **어디든 드래그** | 창을 옮긴다. 드래그와 클릭은 4px 이동으로 가른다 |

**이름표 색과 배지 색은 다를 수 있다.** 이름표는 *지금 보고 있는 세션*의 색이고, 배지는
*기다리는 세션 중 가장 급한 것*의 색이다. 이름표가 회색인데 배지가 파랑이면 "여기는 조용한데
다른 데서 기다린다"는 뜻이다.

## 위치

메뉴의 **위치**에서 다섯 가지를 고른다.

| 고름 | 뜻 |
| --- | --- |
| 자유 위치 · 끌어서 옮기기 | 끌어다 놓은 자리를 그대로 지킨다 (기본값) |
| 우측 하단 고정 | 화면 오른쪽 아래에 붙는다 |
| 우측 상단 고정 | 오른쪽 위 |
| 좌측 상단 고정 | 왼쪽 위 |
| 좌측 하단 고정 | 왼쪽 아래 |

고정해 두면 배율을 바꾸거나 말풍선이 펼쳐져 창 크기가 달라져도 그 모서리에 계속 붙어 있고,
해상도가 바뀌거나 모니터를 붙였다 떼도 다시 붙는다. 아래쪽 모서리에 고정하면 말풍선이 위로
펼쳐진다 — 아래 변을 붙잡아야 화면 밖으로 자라지 않는다.

**끌면 고정이 풀린다.** 손으로 옮긴 자리를 지키는 쪽이 맞다고 봤다. 화면이 여럿이면 마지막에
있던 화면에 붙는다. main 화면은 키보드 초점을 따라 바뀌어서, 그것만 보면 재시작할 때마다
다른 모니터로 건너간다.

## 크기

**크기**에서 `35%` `50%` `65%` `80%` `100%` `120%` `140%`. 고른 크기와 화면 위치는 다음
실행에도 남는다.

크기는 **몸에만** 적용된다. 말풍선과 글자는 훨씬 천천히 줄어서 35% 로 줄여도 무슨 일이
벌어지는지는 그대로 읽힌다(50% 는 글자만 조금 더 눌러 뒀다). 작은 크기에서 레토 옆에 생기는
빈 자리는 클릭이 통과하므로 뒤에 있는 창을 그대로 쓸 수 있다.

## 그 밖의 메뉴

- **AI 세션** — Claude 와 Codex 를 제품별로 나눠 보여준다. 실행 중인 것이 없어도 빈 상태를 띄운다.
  여기서 세션을 고정하거나 다시 자동 추적으로 되돌린다
- **세션 열 곳** — Claude 세션의 목적지만 바꾼다. `자동`(기본) · `VS Code` · `Claude 앱`.
  Codex task 는 ID 체계가 달라 항상 Codex 로 연다
- **스킨** — 기본 레토 외에 꿀벌 · 달 요정 · 천사 날개. 만든 사람 전용 스킨은 자물쇠로 뜬다
- **Claude 연동 확인** — 훅이 걸렸는지, node 가 있는지, 어느 클라이언트에서 소식이 오는지 본다
- **로그인할 때 자동 실행** — 기본값은 꺼짐
- **숨김 · 클릭 통과 · 오른쪽 아래로 이동 · 종료**
- **레토 제거…** — 훅 등록·상태 파일·자동 실행·앱 설정을 정리하고 앱을 휴지통으로 옮긴다.
  확인 창의 기본 단추는 취소다

**세션 열 곳은 자동을 그대로 두는 편이 낫다.** VS Code 와 Claude 앱을 섞어 쓰면 고정값은
반드시 절반을 틀린다. 자동이 잘못 짚을 때만 바꾼다.

## 어디에 무엇이 깔리나

| | 자리 |
| --- | --- |
| 앱 | `~/Applications/Retto.app`(직접 빌드) · `/Applications/Retto.app`(DMG) |
| 세션 상태 | `~/.claude/retto-pet/sessions.json` (옛 `state.json` 도 함께 둔다) |
| 훅 등록 | `~/.claude/settings.json` · `~/.codex/hooks.json` — 기존 항목은 그대로 두고 병합한다 |

훅은 앱을 깔 때 함께 설치된다. `build.sh --install` 과 DMG 설치기가 모두 그 일을 하므로
따로 누를 항목을 두지 않았다.

한글 상태 문구는 **나눔손글씨 미니 손글씨**를 쓴다. 로컬 설치 여부와 상관없이 같아 보이도록
폰트를 앱에 넣고 프로세스 범위로만 등록한다.
