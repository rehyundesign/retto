# 달 고양이 스킨

옷이 아니라 몸 색 자체를 바꾸는 스킨이다. 얼굴 마스크·귀·꼬리는 진한 남색, 몸통은 남색,
가슴·주둥이는 밝은 은빛, 눈은 체리 레드, 이마에 금색 초승달이 **털로 물들어** 있다.

특정 캐릭터를 그대로 옮긴 것이 아니라 배포에 포함한다.

## ⚠️ 배경을 초록으로 쓴다

다른 스킨은 크로마키가 파랑(`#0369F3`)이지만 **이 고양이는 파랗다.** 파란 배경으로
생성하면 잔광 제거(`--despill`)가 몸의 파랑까지 빼서 회녹색이 된다. 실제로 한 번 그랬다.
그래서 배경만 초록(`#00B140`)으로 바꿔 생성하고 정상적으로 잔광을 제거한다.

```sh
python3 remove_chroma_key.py --input gen.png --out k.png \
  --key-color "#00B140" --soft-matte --despill --spill-cleanup
```

## ⚠️ 조각은 배치 **전에** 지운다

초록 키잉은 칸 가장자리에 큰 조각을 남긴다. 그걸 두고 배치하면 bbox 가 부풀어
고양이가 칸 밖으로 밀려난다(한 번 아홉 칸이 반쯤 잘렸다). 자른 칸마다 가장 큰 덩어리만
남긴 뒤 배치해야 한다 — 옷 스킨과 순서가 반대다.

## 생성 묶음

| 생성 | 행 | 칸 |
|---|---|---|
| `gen-idle` | 0 | 7 |
| `gen-run` | 1 | 8 · 행 2 는 좌우 반전 |
| `gen-wave` | 3·4 | 9 |
| `gen-sit` | 6·7 | 12 |
| `gen-fail` | 5 | 8 |
| `gen-sleep` | 8·11 | 12 |
| `gen-gaze9` `gen-gaze10` | 9·10 | 16 |

되돌릴 때는 원래 칸의 발 폭·발 중앙·바닥선에 맞춘다. 달리는 행(발이 뜸)과 누운 칸
(행 11 전부, 행 5 의 c3·c5·c7)은 발이 접혀 발 폭이 안 맞으므로 bbox 로 맞춘다.
