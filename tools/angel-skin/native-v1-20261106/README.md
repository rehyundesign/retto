# 천사 스킨 로컬 앱 연결

HTML에서 선택한 최신 7개 모션을 기존 `천사 날개` 항목에 연결한다. 기본 레토의 귀부터 앞발까지 본체 길이와 얼굴·몸통 윤곽을 비교하고, 날개·펫·이펙트를 제외한 본체 기준으로 표시한다.

- 544px 장면을 448px 기본 원본 좌표에 맞추고 본체 배율 1.06을 공통 적용한다. 그림별 실루엣 크기로 정규화하지 않는다. 앉은 자세 기준선은 484, 수면은 468이다.
- 전체 장면 폭은 원래 petRect 폭의 약 1.287배다. 천사 항목에서만 창 최소 폭을 확보해 다른 창 크기/스킨 동작을 보존한다.
- 원본을 리사이즈하거나 다시 그리지 않고 현재 HTML의 무손실 WebP를 같은 크기의 PNG 프레임으로 내보낸다. 16개 캐릭터 자세와 50ms 이펙트 샘플을 유지한다. 수면은 기존 100ms 이펙트 샘플과 6.4초를 유지한다.
- 전체 장면을 한 번만 그린다. 캐릭터 hold 중에도 별도 경과시간으로 장면 샘플이 바뀌며 이펙트가 진행된다. 별도 고정 gaze 그림은 추가하지 않았고, 기존 드래그는 원래 아틀라스 동작을 유지한다. legacy review는 working으로 연결한다.
- 설치 직전에 아무 랜덤 동작의 실행파일 갱신을 감지했다. 최신 `native-random-20261106` 소스 46개를 해시로 복원한 뒤 천사 분기만 합쳤다. 랜덤 동작의 회귀 검사도 실행했다.

`stage.py` → `export.py` → `patch.py` → `build.py` → `test.py` → `install.py` 순서다. `patch.py`는 복원한 소스에 한 번 적용한다. `build/`와 `recovery/`는 로컬 전용이다. 일반 public build/install 스크립트를 사용하지 않는다.

설치 시 기존 리소스 30,197개를 바이트 그대로 보존했다. 실행파일·Info·서명 복구본은 `recovery/`, 설치한 47개 Swift 소스는 `source-snapshot.tar.gz`에 있다. 설치 후 실제 메뉴 선택/실행 화면 검증 상태는 `installation.json`에 별도로 기록한다. 원본의 모든 해부학적 랜드마크 인증은 여전히 미검증이며, 본체 표시 크기 검사를 그 인증으로 표현하지 않는다.
