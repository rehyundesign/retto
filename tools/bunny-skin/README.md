# 토끼 스킨

분홍 토끼 후드에 딸기 가방을 멘 옷이다. 특정 캐릭터가 아니라 그냥 토끼 옷이라 상표 문제가
없고 배포에 포함한다 (`assets/spritesheet-bunny.webp` 는 레포에 커밋된다).

`ref-short.png` 를 두 번째 참조로 넣어 격자마다 같은 옷을 입힌다.

## ⚠️ 귀를 짧게 그린다 — 길면 고양이가 작아진다

`costume-ref.png` 이 처음 승인받은 그림인데 **귀가 너무 길다.** 칸(240px)에서 바닥 여유 5px 을
빼면 235px 이고 기본 고양이 몸이 198~201px 이니 귀가 머리 위로 더할 수 있는 높이는 34px 뿐인데,
긴 귀는 67px 을 썼다. 넘치지 않게 전체를 0.874배로 줄였더니 **몸이 기본 대비 0.88 이 됐다** —
꿀벌 1.03·달 고양이 1.01·천사 1.08 사이에서 토끼만 작았고, 스킨을 바꾸면 고양이가 눈에 띄게 줄었다.

귀를 짧게(머리 높이의 1/3, 끝이 바깥으로 접힘) 다시 생성해 **0.96** 까지 올렸다.
`ref-short.png` 가 그 짧은 귀 기준 그림이고, `costume-prompt-long-ears.txt` 는 긴 귀 시절 프롬프트다.

- **`sit` 묶음(행 6·7)이 유독 귀를 길게 그린다.** 프롬프트 끝에 "긴 토끼 귀를 그리지 마라"를
  한 번 더 붙여야 짧게 나온다. 그 묶음만 다시 생성하면 공통 배율이 0.913 에서 0.964 로 올랐다

## 어떻게 만들었나

옷은 자세마다 형태가 달라져 레이어 합성이 안 된다. 자세 묶음마다 기본 아틀라스 칸을 격자에
넣고 한 번에 입혔다 — 한 장 안에서 만들어야 옷이 칸마다 안 달라진다. 꿀벌·달 고양이와 같다.

| 생성 | 행 | 칸 |
|---|---|---|
| `gen-idle` | 0 | 7 |
| `gen-run` | 1 | 8 · 행 2 는 좌우 반전 |
| `gen-wave` | 3·4 | 9 |
| `gen-fail` | 5 | 8 |
| `gen-sit` | 6·7 | 12 |
| `gen-sleep` | 8·11 | 12 |
| `gen-gaze9` `gen-gaze10` | 9·10 | 16 |

## ⚠️ 되돌릴 때 다시 재지 않는다 — 넣을 때 쓴 배율을 뒤집는다

**기본 아틀라스는 행마다 고양이 크기가 다르다** (행 4 는 행 3 보다 12% 작다). 격자에 넣을 때
칸마다 다른 배율로 줄여 넣으므로, 되돌릴 때 그 배율을 그대로 뒤집어야 원래 크기 관계가 남는다.

칸마다 다시 재면 그 차이가 지워진다. 모델이 얼마나 키워 그렸는지만 중앙값으로 보정하고,
그 값은 **폭으로** 잰다 — 토끼 귀가 높이만 늘려서 높이로 재면 몸이 그만큼 작아진다.

**⚠️ 보정값은 묶음별이 아니라 전체에서 하나로 정한다.** 묶음마다 정하면 묶음 사이의 크기
관계가 깨진다 — 달리기 0.910·시선9 1.012 로 11% 벌어져서 **달릴 때 후드가 눈에 띄게 작아졌다.**
전체 하나(0.953)로 합치니 공통 배율이 0.96 에서 1.00 이 됐고, 행별 몸 폭이 0.95~1.05 로 모였다.

- 처음에 칸마다 bbox 높이로 맞췄더니 행 5 에서 누운 칸만 0.62 배, 선 칸은 0.88 배가 됐다.
  넘어지는 애니메이션에서 고양이가 갑자기 작아졌다
- 발 자리는 기준점으로만 쓴다. 달리는 행(1·2)과 누운 칸(행 11 전부, 행 5 의 c3·c5·c7)은
  발이 뜨거나 접혀 있어 bbox 아래 가운데를 기준점으로 쓴다

## ⚠️ 귀가 높아 여백을 두 번 벌려야 한다

토끼 귀는 기본 고양이의 머리 위 여백보다 높다. 두 군데에서 잘린다.

| 어디서 | 무엇이 | 어떻게 막나 |
|---|---|---|
| 생성 격자 | 윗줄 귀가 이미지 밖에서 잘림 | `dress.CAT_H` 를 290 으로 낮춰 머리 위를 145px 로 벌린다 |
| 되돌린 칸 | 귀가 칸 위에서 잘림 (17칸이 잘렸다) | `fit_scale` 이 전체에 같은 배율을 곱한다 (짧은 귀로 0.964) |

**칸마다 따로 줄이지 않는다.** 그러면 재생 중에 크기가 흔들린다.

## ⚠️ 시선 행은 한 칸씩 만든다 — 여러 칸을 한 장에 넣으면 후드가 안 돈다

행 9·10 은 마우스를 따라 고개를 돌리는 16방향이다. **몸은 정면인데 고개만 도는 유일한 행이고,
여기서만 후드가 깨진다.** 모델이 후드를 몸에 붙은 것으로 취급해서, 얼굴만 돌려 넣고 후드는
정면 돔 그대로 둔다 — 화면에서 「모자만 정면」으로 어색하게 보인다.

**몸 전체가 옆을 보는 행(달리기·넘어짐·웅크림)은 문제가 없다.** 그 행들은 그냥 격자로 만든다.

고치는 데 두 가지가 다 필요하다.

**① 각도별 후드 참조(`ref-turn.png`)를 세 번째 참조로 넣는다.** 같은 인형을 정면·45도·완전
옆모습·뒤에서 찍은 네 컷이다. 후드가 각 각도에서 어떤 모양인지 이걸로 알려 준다.

**② 칸을 하나씩 만든다** (`cellgrid`·`cellcut`). 4칸씩 묶어도 후드가 안 돈다 — 한 칸에 하나여야 따라온다.

```sh
$PY skin.py cellgrid 9 4
python3 "$S" "$(cat gaze-cell.txt)" --ref grid-r9c4.png --ref ref-short.png \
  --ref ref-turn.png -o gen-cell/c9-4.png --aspect 1:1 --size 1K
$PY skin.py cellcut 9 4 gen-cell/c9-4.jpg
```

`gaze-cell.txt` 가 한 칸용 프롬프트다. 여러 칸용(`costume-prompt.txt`)과 달리 "첫 이미지에
고개가 돌아간 만큼 후드도 그만큼 돌려라"를 가장 앞에 둔다.

### 여기서 네 번 실패했다

| 시도 | 후드 각도 | 깨진 것 |
|---|---|---|
| 도표형 참조 시트 | 정확 | 그림체가 납작한 만화로 (검은 외곽선) |
| 봉제인형 사진 참조 | 정확 | 몸이 참조의 **서 있는 자세**로 끌려감 |
| 자세 고정 문구 추가 | 정확 | 한 칸이 뒤통수 · 배경이 청록 그라데이션이라 크로마키 실패 |
| 4칸씩 묶어 생성 | 얕음 | 새 칸이 커서 공통 배율이 0.76 으로 — 크기 문제 재발 |

- **참조 시트는 봉제인형 사진으로 만든다.** "turnaround"·"diagram" 이라고 쓰면 납작한 일러스트가
  나오고 그 그림체가 결과에 옮는다. "회전대에 올려 네 각도에서 찍은 사진"으로 쓴다
- **참조에서 후드만 가져오라고 못 박는다.** 안 그러면 몸 자세까지 따라온다
- **배경을 "완전히 평평한 단색 파랑, 그라데이션·청록·바닥·그림자 없음"으로 길게 쓴다.**
  한 번 청록 그라데이션이 나와 크로마키가 통째로 실패했다. 자를 때 네 모서리가 키 색에서
  얼마나 떨어졌는지 재서 걸러낸다

## ⚠️ 격자에서 폭도 맞춘다

`dress.make_grid` 는 높이만 맞춘다. 누운 자세는 옆으로 길어서 폭이 슬롯(448px)을 넘고 옆 칸과
붙는다. 붙은 채로 생성하면 모델이 둘을 한 덩어리로 보고 통째로 키운다 — `sleep` 에서 누운
여섯 칸이 가로로 다 겹쳤다. `skin.py` 의 `make_grid` 가 폭·높이를 둘 다 맞춘다.

## ⚠️ 격자를 모델이 받는 비율로 채운다

받는 비율은 정해진 목록뿐이다. 격자(1792×960)를 그대로 `16:9` 로 넣으면 가로가 5% 눌린다.
오른쪽·아래로만 채워 정확한 비율로 만든다 — 가운데로 채우면 칸 자리가 밀려 자를 때 어긋난다.

## 만드는 법

파이썬 환경이 먼저 필요하다 (레포 루트에서 한 번).

```sh
python3 -m venv .venv && .venv/bin/pip install pillow numpy scipy
```

```sh
cd tools/bunny-skin
PY=../../.venv/bin/python
S=~/Documents/chainshift/planning/.claude/skills/image-gen/scripts/gen-image.py
export GEMINI_API_KEY=...

for b in idle run wave fail sit sleep gaze9 gaze10; do $PY skin.py grid $b; done

# 2행 격자는 16:9, 3행 격자(wave·sit·sleep)는 5:4 로 넣는다
python3 "$S" "$(cat costume-prompt.txt)" -o gen-idle.png \
  --ref grid-idle.png --ref ref-short.png --aspect 16:9 --size 2K

for b in idle run wave fail sit sleep gaze9 gaze10; do $PY skin.py cut $b gen-$b.jpg; done
$PY skin.py atlas
cwebp -lossless -exact -z 9 atlas.png -o ../../assets/spritesheet-bunny.webp
```

**생성물은 눈으로 보고 넘어간다.** 한 칸이 통째로 어긋나는 일이 있다 — `gaze9` 의 한 칸이
발 폭 75px(같은 묶음은 265px)로 잡혀 발만 확대된 그림이 됐다. 지금은 배율을 재지 않으므로
같은 사고는 안 나지만, 옷이 칸마다 달라지거나 자세가 바뀌는 것은 검사가 못 잡는다.

## 검사

```sh
swift ../sprite-scale.swift measure atlas.png     # 행별·칸별 크기가 고른가
zsh ../../macos/scripts/build.sh                  # 자체 검사가 skinsOK 를 찍는가
```

**다른 스킨과 몸 크기를 비교한다.** 이게 「스킨을 바꾸니 고양이가 작아졌다」를 잡는 검사다.
기본 대비 몸 폭 중앙값이 꿀벌 1.03·달 고양이 1.01·천사 1.08 이므로 토끼도 1.0 근처여야 한다.

2026-09-04 기준: 칸 가장자리에 닿은 칸 0, 공통 배율 1.000, 몸 폭 중앙값 1.00(행별 0.94~1.05),
바닥선이 행마다 기본과 일치, 시선 방향 16/16 일치, 자체 검사 `"skins":6,"skinsOK":true`.

## 파일

- `ref-short.png` — 짧은 귀 기준 그림. 지금 쓰는 것
- `costume-ref.png` — 처음 승인받은 그림(긴 귀). 출처로 남긴다
- `costume-prompt.txt` · `costume-prompt-long-ears.txt` — 생성 프롬프트(지금 것 / 긴 귀 시절)
- `dress.py` — 격자·발 측정 공용 함수 (꿀벌 스킨에서 가져왔다)
- `skin.py` — `grid` · `cut` · `atlas` 세 단계
- `gaze-cell.txt` — 시선 행 한 칸용 프롬프트
- `ref-turn.png` — 후드를 네 각도에서 찍은 참조. 시선 행에 세 번째 참조로 넣는다
- `grid-*.png` `gen-*.jpg` `gen-*/` `atlas.png` — 중간물. 47MB 라 커밋하지 않는다
