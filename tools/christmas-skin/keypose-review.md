# 움직임 수정 기록

기존 시안은 상태별 원본 하나에 국소 픽셀 변형을 적용했다. 자세 변화가 부족하고 손·다리 동작이 흐르는 문제가 있어 배포 후보에서 제외한다.

수정본은 이미지 생성 도구로 만든 독립 자세 원본을 사용한다. 캐릭터의 픽셀 변형이나 이미지 간 혼합을 적용하지 않는다. 같은 자세를 유지하거나 동작을 반대로 이어갈 때는 원본을 재사용한다. 재생 프레임 수와 독립 원본 수를 검증 기록에서 구분한다.

달리기는 뻗기·접기·모으기·반대쪽 뻗기의 8장 순환으로 만들고, 왼쪽 이동은 오른쪽의 반전으로 만든다. 나머지 동작은 앞발과 소품의 실제 자세 변화, 눈 깜빡임, 준비·점프·착지, 호흡 자세를 사용한다. 의상과 상태별 소품·이펙트는 승인한 시안을 유지한다.

새 원본은 `gen-keypose-sources/`, 수정본 셀과 내부 확인 결과는 `gen-keyframes/`에 보관한다. 설치본과 앱 소스는 변경하지 않는다.
