### 현재 행동 연결·시선 경계 수정

프레임 수 자체로 자연스러운 동작을 판정하지 않는다. 앞뒤 기준 컷을 함께 참고해서 다리·앞발·소품의 연결 자세를 다시 생성했다. 생성한 시간 비율만 믿지 않고 실제 자세를 비교해 순서를 조정한다. 인사에는 낮은 첫 팔 들기, 점프에는 몸통·무릎이 연결된 준비 자세를 추가했다. 현재 독립 중간 자세 등록은 40개이며 유지·역방향 재생과 미사용 후보가 포함되므로 40개 모두가 각각 다른 최종 셀에 대응하지는 않는다.

`christmas-16-timing.json`의 `frame_seconds`를 앱과 웹에서 함께 사용한다. 움직이는 손동작 컷은 0.085초, 눈 깜빡임은 0.055초, 점프는 0.065초를 기본 간격으로 쓰고 남은 주기 시간은 정지·끝 자세에 배분한다. 달리기는 기존 0.0425초, 수면은 0.225초를 유지한다. 앱은 해당 프레임 유지 시간마다 다음 프레임을 예약한다. 전체 주기를 16으로 나눈 일정 간격으로 모든 컷을 느리게 만드는 방식은 제외했다. 이펙트 타이머는 그대로 별도 20fps다.

시선은 `gaze-*-registered.png`의 연결된 머리·목도리를 곡선 경계를 따라 기본 몸 위에 합성한다. 투명 경계는 premultiplied alpha로 처리하고 꼬리는 기본 컷으로 유지한다. 16방향 모두 y>=484 몸·발 픽셀의 기본 컷 일치를 검사했다. 전신 신규 도약 2컷에는 기존 보호 마스크 동일성 판정을 적용하지 않는다. 점프는 자세 원본과 머리 높이에 맞춘 캐릭터 전체 이동을 함께 사용한다.

검토는 160개 동작 셀과 시선 16개를 1×의 밝은/어두운 배경에서 수행했다. 빌드·설치본 자체 테스트에는 16개 프레임 유지 시간의 합계·최소 간격·다른 스킨 시간 보존을 포함한다. 이미지 검사는 투명 RGB 0, 시선 하체 보존, 여백과 자세 변경 범위를 확인한다. 이러한 검사와 시각 검토는 운동학적 연속성이나 사용자 체감이 완벽하다는 수치 보증은 아니다.

## 이전 시안 제작 방식

- `assets/retto-christmas-concept.png`가 의상·캐릭터 기준이다.
- 상태별 원본은 이미지 생성 도구로 각각 만들었다. 승인한 상태 보드는 자세 참고로만 사용했다. 보드를 잘라 애니메이션 셀로 쓰지 않았다.
- 정면 자세는 기준 얼굴의 파란 홍채 사이 거리를 이용해 첫 프레임의 크기를 맞춘다. 실제 측면 달리기와 누운 자세는 별도의 시점 규격을 사용한다.
- 각 셀은 해당 상태의 독립 원본에서 직접 렌더링한다. 앞발·리본·종·꼬리·흉곽의 작은 변형을 계산하며, 얼굴 영역은 고정한다. 점프는 캐릭터만 수직으로 이동한다.
- 왼쪽 이동은 오른쪽 이동의 반전이다. 장식·별·눈송이·종소리 표시와 점프의 선물은 캐릭터 앞뒤에 따로 그린다.

`motion.json`에 상태별 원본, 크기 기준, 바닥선, 네 다리의 자세, 동작 영역과 시간 간격을 기록했다. 생성 프롬프트는 `generation-prompts.json`에 있다.

## 이전 시안 재생과 재생성

현재 `preview/index.html`은 수정본을 재생한다. 이전 시안의 전체 재생 파일은 `preview/motion.gif`로 별도 보관한다.

Node.js와 이미 사용 가능한 `sharp`가 필요하다. 설치나 의존성 변경 없이 기존 런타임을 사용한다.

```sh
RETTO_NODE_MODULES=/path/to/existing/node_modules node tools/christmas-skin/motion.mjs
```

원본 파일은 `gen-anchors/`, 프레임과 별도 이펙트는 `gen-frames/`에 보관한다. 두 폴더는 저장소의 기존 생성물 제외 규칙에 해당한다.

## 확인 범위

렌더링 도구는 원본 배치의 잘림, 모든 캐릭터 셀의 여백, 같은 상태의 얼굴 픽셀 유지 여부를 확인한다. 최종 GIF와 프레임은 실제 표시 규격인 224×320으로 검토한다. GIF 저장 과정에서 같은 화면이 연속되는 경우 해당 프레임이 병합될 수 있다.

2026-10-08에 `/Users/luxia/Applications/Retto.app`을 교체하고 `크리스마스` 스킨을 선택했다. 리락쿠마 개인 스킨 두 개를 보존했다. 이전 설치본은 `gen-production/installed-backups/`에 보관한다.

앱은 `spritesheet-christmas-character.webp`를 사용하며 `ChristmasEffects.swift`가 캐릭터 앞뒤 효과를 20fps로 재생한다. 캐릭터가 시선을 유지해도 효과는 갱신된다. 기본 상태의 머리 위 전구와 점프 아래 선물상자는 없다.

검증: Swift 타입 검사, `build.sh --app-only --keep-build`, 앱 `--self-test` 전체 통과(크리스마스 아틀라스 규격 및 모든 상태·좌우 이동·시선의 시간별 효과 변화 포함), 코드 서명 검사, 설치본 바이너리·아틀라스 SHA-256 일치. 실제 앱에서 스킨을 선택하고 표시 화면을 확인했다. `preview/installed-app.png`는 설치된 앱 화면이며 `preview/native-app-preview.png`는 앱 코드로 렌더링한 상태·배율 비교다. 시선 16개 각각의 실제 앱 상호작용 및 원본 보호 픽셀 전체 검사는 별도 수행하지 않았다.
