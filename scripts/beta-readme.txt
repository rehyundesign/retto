레토 (Retto) __VERSION__ — 베타
Claude Code 상태에 맞춰 움직이는 랙돌 고양이


■ 설치

  1. 이 폴더 안의  설치.command  를 터미널 창으로 끌어다 놓고 엔터

     터미널은 Spotlight(⌘+스페이스)에서 "터미널" 로 찾으면 됩니다.
     끌어다 놓으면 경로가 입력되고, 엔터를 치면 알아서 설치합니다.

  2. 화면에 고양이가 나오면 끝입니다.


■ 왜 그냥 더블클릭하면 안 되나요

  아직 애플 개발자 서명·공증을 붙이지 않은 베타라서, 앱을 그냥 열면
  macOS 가 "손상되었기 때문에 열 수 없습니다" 라고 막습니다.
  앱이 손상된 게 아니고, 서명이 없어서 나오는 경고입니다.

  설치.command 가 하는 일이 그 격리 표시를 떼는 것입니다.
  직접 하고 싶으면 터미널에 아래 한 줄이면 됩니다.

    xattr -dr com.apple.quarantine "$HOME/Applications/Retto Claude Pet.app"


■ 필요한 환경

  · 애플 실리콘 맥 (M1 이상)  — 인텔 맥에서는 실행되지 않습니다
  · macOS 13 (Ventura) 이상
  · Claude Code
  · Node.js  — 상태를 읽는 훅이 node 로 돕니다 (https://nodejs.org)


■ 무엇을 건드리나요

  · ~/Applications/Retto Claude Pet.app          앱
  · ~/.claude/retto-pet/                          상태 파일과 훅
  · ~/.claude/settings.json                      훅 등록
    이미 있던 훅은 건드리지 않고, 고치기 전에 백업을 남깁니다.


■ 색이 뜻하는 것

  초록   Claude 가 일하는 중
  파랑   네 결정을 기다리는 중 (권한 요청·질문)
  주황   답이 끝났는데 아직 안 본 것
  빨강   실패
  회색   조용함


■ 쓰는 법

  · 몸통이나 말풍선을 클릭   →  그 세션을 Claude Code(또는 Claude 앱)에서 엽니다
  · 말풍선 오른쪽 위 주황 배지 →  답이 끝난 세션이 여럿일 때 목록이 나옵니다
  · 말풍선 위에 마우스를 올리면 →  잘린 문장이 있을 때 아래로 펼쳐집니다
  · 레토를 끌면            →  옮겨집니다

  발바닥(메뉴바 오른쪽)을 클릭하면 메뉴가 나옵니다.

  · 크기        35% ~ 140% 일곱 단계
  · 위치        자유 위치, 네 모서리 고정 중에서 고릅니다. 고정하면 크기가
                바뀌어도 그 모서리에 계속 붙어 있고, 끌면 고정이 풀립니다
  · 세션 열 곳   VS Code / Claude 앱 / 자동(세션이 시작된 곳)
  · 완료 표시 지우기   주황 배지를 한 번에 내려놓습니다
  · 로그인할 때 자동 실행
  · 클릭 통과     마우스가 레토를 통과해 뒤 창을 누릅니다
  · Retto 정보    만든 사람과 버전
  · 레토 제거…    훅과 상태 파일까지 정리합니다


■ 언제 자나요

  · 모든 세션이 조용한 채로 10분  →  이름표가 "레토" 로 바뀌고 Zzz
  · 답을 다 해놓고 아무도 안 본 채 30분  →  말풍선은 그대로 두고 그림만 잠듭니다
                                            (기다리다 졸은 모습입니다)

  어느 세션이든 다시 움직이면 바로 깹니다.


■ 주황 배지는 언제 사라지나요

  · 레토를 눌러 그 세션에 다녀오면
  · 그 세션 창을 3초 이상 열어 놓고 있으면
  · 발바닥 메뉴의 「완료 표시 지우기」를 누르면
  · 그 세션에 다시 말을 걸면

  두 번째(창을 보고 있으면 자동으로)는 화면 기록 권한이 필요합니다.
  macOS 가 창 제목 읽기를 그 권한으로 묶어 두었기 때문입니다.
  레토는 화면을 녹화하지도 저장하지도 않고, 맨 앞 창의 제목 한 줄만 읽습니다.

  켜져 있는지는 발바닥 메뉴 > 「Retto 정보」에서 "자동 읽음 판정" 줄로 확인합니다.
  꺼져 있으면 같은 창의 「화면 기록 설정 열기」 단추로 바로 갈 수 있습니다.
  권한을 주지 않아도 나머지 세 가지 길은 그대로 동작합니다.

  시간이 지나 저절로 사라지지는 않습니다. 돌려놓고 한참 뒤에 돌아오는 것이
  이 배지의 쓸모라고 봤습니다.
