# macOS 오버레이 (Swift)

모든 Space 와 전체화면 앱 위에 상주하는 오버레이 본체다.

```sh
macos/scripts/build.sh             # 빌드 + 셀프 테스트 + dist/ 에 zip·dmg
macos/scripts/build.sh --install   # 위 + ~/Applications 설치 후 재실행
```

- 몸·말풍선·배지가 그려지는 규칙 — [화면에 보이는 것](../docs/오버레이.md)
- 메뉴에서 고를 수 있는 것 — [메뉴에서 무엇을 고를 수 있나](../docs/사용법.md)
