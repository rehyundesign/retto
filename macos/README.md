# Retto — macOS Desktop Overlay

Claude Code와 Codex 상태에 맞춰 움직이며 모든 macOS 데스크탑(Space)과 전체화면 앱 위에 계속 보이는 레토입니다. 별도 앱을 두지 않고 이 오버레이 하나가 두 제품의 세션을 함께 추적합니다.

레토의 한글 상태 문구는 **나눔손글씨 미니 손글씨**(`NanumMiNiSonGeurSsi`)를 사용합니다. 로컬 설치 여부와 관계없이 동일하게 보이도록 폰트를 앱에 포함하고 프로세스 범위에서만 등록합니다.

## 동작

- 프롬프트 전송: 생각하며 달리기
- 도구 사용: 꼼꼼히 살펴보기
- 권한/입력 요청: 기다리기
- 도구/API 실패: 풀이 죽기
- 답변 완료: 손 흔들고 쉬기
- 쉬는 중·작업 중·손 흔들 때 마우스 이동: 16방향으로 시선 따라오기

VS Code 에서 Claude Code를 돌리든, Claude 앱이나 Codex 앱에서 대화를 시작하든 똑같이 잡습니다. 설치기가 Claude와 Codex 양쪽 설정에 훅을 붙이고 같은 세션 레지스트리로 모읍니다. 제품별 세션 ID는 충돌하지 않게 구분합니다.

Claude Code·Codex 세션을 여러 개 열어도 각각 따로 추적합니다. 기본값은 **입력 요청 → 실패 → 답변 완료 → 작업 중 → 살펴보는 중 → 쉬는 중** 순서로 지금 확인해야 할 세션을 자동 표시합니다.

앞의 세 가지(입력 요청·실패·답변 완료)가 Claude Code 사이드바 아이콘에 파란 숫자로 뜨는 그 묶음입니다. 확장은 세션 상태를 `idle`·`running`·`waiting_input` 셋으로만 보고하고 `waiting_input` 개수를 배지로 띄우는데, 거기에는 권한 요청뿐 아니라 턴이 끝나 답을 기다리는 상태도 들어갑니다. 그래서 레토도 이 셋을 작업 중인 세션보다 위에 둡니다. 이 상태에서는 말풍선이 레토의 말 대신 그 세션의 제목을 보여주고, 레토를 누르면 그 세션의 창으로 갑니다. 메뉴바 **발바닥 → AI 세션**에서 원하는 세션을 고정하거나 다시 자동 추적으로 바꿀 수 있습니다. 고정해 둔 동안에도 손이 필요한 세션이 생기면 레토는 그쪽을 먼저 보여줍니다. 파란 숫자가 떴는데 레토가 딴 데를 보고 있으면 배지가 아무 뜻이 없기 때문입니다. 손이 필요한 세션이 없어지면 다시 고정한 세션으로 돌아옵니다.

말풍선은 동물의 숲 대화창처럼 생겼습니다. 왼쪽 위에 얹힌 이름표에 **세션 타이틀**이 적히고, 그 색이 지금 상태를 말합니다.

| 배경 | 글자 | 뜻 | 상태 |
|---|---|---|---|
| `#73DF5D` | `#0A5225` | 진행 중 | 생각하는 중 · 도구 쓰는 중 · 세션 재개 |
| `#0885FE` | `#FFFFFF` | 내 답을 기다림 | 권한·입력 요청 |
| `#FF7009` | `#FFFFFF` | 완료 | 답변을 마침 |
| `#F82D39` | `#FFF499` | 문제 | 도구·API 실패 |
| `#848484` | `#FFFFFF` | 쉬는 중 | 아무 일도 없음 |

이름표 이름은 세션 타이틀입니다. 직접 바꾼 이름이 있으면 그것을, 없으면 Claude 가 붙인 이름을 쓰고, 열두 글자를 넘으면 뒤를 `…` 로 접습니다.

색은 이 네 가지 뜻으로만 씁니다. 상태가 일곱 개여도 색으로는 넷만 구분되니 흘깃 봐도 무슨 뜻인지 압니다. 말풍선 안에는 **Claude 가 마지막으로 한 말**이 그대로 적혀, 그 창으로 가지 않고도 무슨 얘기가 오갔는지 읽을 수 있습니다. 아직 답이 없는 세션에서는 레토가 하는 말이 대신 들어갑니다.

멘트가 길어 잘렸으면 말풍선 아래에 노란 삼각형이 생깁니다. 그때 **말풍선에 마우스를 올려 잠깐 두면 아래로 펼쳐져** 더 읽을 수 있고, 벗어나면 곧바로 접힙니다. 레토의 위치는 펼쳐도 그대로입니다.

여러 세션이 확인을 기다리면 레토 위 배지에 개수가 나타납니다.

창의 아무 곳이나 드래그해서 옮길 수 있습니다. 레토를 우클릭하거나 메뉴바의 발바닥 아이콘을 누르면 숨김, 크기, 클릭 통과, 오른쪽 아래로 이동, 종료를 제어할 수 있습니다. **AI 세션**은 Claude와 Codex를 제품별로 나누고, 실행 중인 task가 없어도 빈 상태를 표시합니다. **AI 세션 열 곳 → Codex task → Codex 앱 · 자동**을 누르면 Codex 자동 라우팅 방식과 훅 설정 위치를 확인할 수 있습니다.

메뉴의 **위치**에서 다섯 가지를 고릅니다.

| 고름 | 뜻 |
|---|---|
| 자유 위치 · 끌어서 옮기기 | 끌어다 놓은 자리를 그대로 지킵니다(기본값) |
| 우측 하단 고정 | 화면 오른쪽 아래에 붙습니다 |
| 우측 상단 고정 | 오른쪽 위 |
| 좌측 상단 고정 | 왼쪽 위 |
| 좌측 하단 고정 | 왼쪽 아래 |

고정해 두면 배율을 바꾸거나 말풍선이 펼쳐져 창 크기가 달라져도 그 모서리에 계속 붙어 있고,
화면 해상도가 바뀌거나 모니터를 붙였다 떼도 다시 붙습니다. 아래쪽 모서리에 고정한 경우에는
말풍선이 위로 펼쳐집니다 — 아래 변을 붙잡아야 화면 밖으로 자라지 않기 때문입니다.

**끌면 고정이 풀립니다.** 손으로 옮긴 자리를 지켜 주는 것이 맞다고 봤습니다. 화면이 여럿일 때는
마지막에 있던 화면에 붙습니다(main 화면은 키보드 초점을 따라 바뀌어서, 그것만 보면 재시작할 때마다
다른 모니터로 건너갑니다).

레토가 Claude Code·Codex 상태를 읽는 통로(훅)는 앱을 깔 때 함께 설치됩니다. `build.sh --install` 과 베타 설치기가 모두 그 일을 하므로 따로 누를 항목을 두지 않았습니다.

메뉴의 **로그인할 때 자동 실행**은 선택 사항이며, 켜면 Mac에 다시 로그인한 뒤에도 레토가 자동으로 나타납니다.

누르는 곳마다 하는 일이 다릅니다.

- **레토 몸통**: 톡 누르면 한 번 뛰어오르면서, 그 세션이 사는 창을 앞으로 보내고 그 세션까지 되살립니다. VS Code 라면 새 창을 만들지 않고 그 탭을 되살립니다.
- **⌥(Option) + 클릭**: 창만 앞으로 보내고 탭은 건드리지 않습니다. 세션 목록에서 고를 때도 같습니다.
- **상태 말풍선**: 몸통과 같습니다. 마우스를 올리면 오른쪽에 ↗ 가 나타납니다.
- **빨간 배지**: 손이 필요한 세션이 하나면 바로 열고, 여러 개면 목록을 띄워 고르게 합니다. 배지는 끌어서 레토의 네 모서리 중 어디로든 옮길 수 있고 그 위치를 기억합니다.
- **어디든 드래그**: 창을 옮깁니다. 드래그와 클릭은 4px 이동 임계값으로 구분됩니다.

누르면 **그 세션이 시작된 앱**이 열립니다. VS Code 에서 시작한 Claude 세션은 VS Code 로, Claude 앱에서 시작한 세션은 Claude 앱으로, Codex task는 Codex로 갑니다. Codex task ID와 Claude session ID는 서로 호환되지 않으므로 Codex 세션은 항상 Codex로 엽니다. 메뉴바 **발바닥 → 세션 열 곳**은 Claude 세션의 목적지만 바꿉니다.

| | 뜻 |
|---|---|
| 자동 · 세션이 시작된 곳 | 기본값. 세션마다 알아서 갈라 보냅니다 |
| VS Code | 무엇을 누르든 VS Code 로 |
| Claude 앱 | 무엇을 누르든 Claude 앱으로 |

둘을 섞어 쓰면 고정값은 반드시 절반을 틀리므로 자동을 그대로 두는 편이 낫습니다. 자동이 잘못 짚을 때만 바꾸세요.

배지 색도 같은 네 가지를 씁니다. 다만 이름표는 **보고 있는 세션**의 색이고 배지는 **기다리는 세션 중 가장 급한 것**의 색이라 서로 다를 수 있습니다. 이름표가 회색인데 배지가 파랑이면 "여기는 조용한데 딴 데서 너를 기다린다"는 뜻입니다.

메뉴바 **발바닥 → 크기**에서 `35%`, `50%`, `65%`, `80%`, `100%`, `120%`, `140%`를 선택할 수 있습니다. 선택한 크기와 화면 위치는 다음 실행에도 유지됩니다.

크기는 레토의 몸에만 적용됩니다. 말풍선과 글자는 몸보다 훨씬 천천히 줄어들어, 레토를 35% 로 줄여도 지금 무슨 일이 벌어지는지는 그대로 읽힙니다(50% 는 글자만 조금 더 눌러 두었습니다). 작은 크기에서 레토 옆에 생기는 빈 공간은 클릭이 통과하므로 뒤에 있는 창을 그대로 쓸 수 있습니다.

## 설치 상태

앱은 `~/Applications/Retto.app`(직접 빌드) 또는 `/Applications/Retto.app`(dmg)에 설치됩니다. Claude Code와 Codex 상태는 `~/.claude/retto-pet/sessions.json`에서 제품·세션별로 읽으며, 기존 호환을 위해 `state.json`도 함께 유지합니다. 훅 등록은 `~/.claude/settings.json`과 `~/.codex/hooks.json`에 기존 항목을 보존한 채 병합합니다.

자동 실행은 기본값으로 켜지지 않습니다. 원할 때 메뉴에서 직접 켤 수 있습니다.
